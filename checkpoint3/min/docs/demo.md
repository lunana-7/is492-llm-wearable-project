# Min’s demo cues

**Slide 4 · Edge case and recovery.** Ask a consenting speaker to say “I will bring the revised water quality chart to office hours.” Run the microphone demo. Show the draft, discard it and show that the requested file was never created. Run it again, edit the quote and approve. Open the saved note. If the microphone fails, disclose the switch to the provided synthetic clip and run the same two live models.

**Slide 6 · Safety.** Explain the two separate decisions: permission to process speech and approval to save an edited follow-up. Show the saved note and delete it. Explain that a verbatim quote can still contain a transcription error or omit context.

**Rehearsal.** Check microphone permission and audio quality on the presentation laptop, warm the models, and time the demo with the rest of the team.
